# Строка — сервер анализа рифм

Отдельный HTTP-сервис на FastAPI с русской моделью RhymeTagger и фонетической транскрипцией eSpeak NG. Предназначен для приложения «Строка»; результаты модели приблизительны.

## Установка и запуск

Требуются Python 3.10+ и системная программа `espeak-ng` (в Debian/Ubuntu: `sudo apt-get install espeak-ng`).

```sh
python3 -m venv .venv
. .venv/bin/activate
pip install -r requirements.txt
python -m nltk.downloader punkt punkt_tab
uvicorn app:app --host 127.0.0.1 --port 8002
```

Скачивание ресурсов NLTK необходимо при первой настройке. Для интеграции сайт должен проксировать `/api` на адрес сервиса, по умолчанию `http://127.0.0.1:8002`. Запросы из браузера идут на сайт и его прокси, а не на localhost посетителя. У сайта адрес сервиса можно настроить переменной `RHYME_API_URL` до запуска Vite.

## API

- `GET /api/health` — состояние и название модели.
- `POST /api/rhymes` с JSON `{ "terms": ["река́", "дом", "рука́", "гром"] }`. Допускается до 350 слов или коротких сочетаний (до 200 символов каждое). Ответ содержит `labels` (номер группы либо `null` для каждого элемента), `stress_uncertain` (индексы, для которых ручное ударение не удалось надёжно перенести в IPA) и `model`.

Рифмовка вычисляется моделью, обученной на строковых окончаниях. Использование для отдельных слов и составных рифм приблизительно. Если разметка ручного ударения не совпадает с транскрипцией по числу гласных, используется ударение eSpeak, а индекс попадает в `stress_uncertain`.

Текст передаётся только этому сервису, который не сохраняет его и не вызывает внешние сервисы для анализа. На этапе установки ресурсы скачиваются из сети.

## Тестирование

```sh
python -m unittest discover -s tests
```

Для публичного развёртывания нужны аутентификация, ограничение запросов и HTTPS. Этот сервис не предназначен для прямой публикации в интернет без дополнительной защиты.
